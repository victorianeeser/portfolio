<SectionTitle>Ten Heuristics, One App</SectionTitle>

I reviewed the current Oura app against Nielsen’s ten usability heuristics.

<HeuristicCards
  items={[
    {
      title: 'Visibility of status',
      question: 'Do you know where you are in the system and where you can go next?',
      example: 'Elevator buttons lighting up',
      findings: [
        'The bottom navigation bar and Home overview show where you are and how you’re doing today.',
        'Each section, like Sleep, has a consistent header and back button.',
      ],
    },
    {
      title: 'System vs. real world',
      question: 'How similar are the digital and physical experiences?',
      example: 'Shopping carts on a website vs. in a store',
      findings: [
        'The ring is effortless: it just sits on your finger and needs no interaction.',
        'The app is the opposite: **you dig through charts, scores and insights** to get value.',
      ],
    },
    {
      title: 'User control and freedom',
      question: 'Does the user get lost in the experience at any time?',
      example: 'Back buttons; the ability to edit a shopping cart',
      findings: [
        'Deeper views, like past trends or tags, **aren’t easy to find or return from.**',
        'Dozens of metrics with no priority leave newer users unsure what matters today.',
      ],
    },
    {
      title: 'Consistency and standards',
      question: 'Does the system follow patterns?',
      example: 'Buttons in the same place; no new functionality introduced mid-experience',
      findings: [
        'The fixed bottom navigation bar means users can always get back to the main areas.',
        'Data cards repeat across screens, so users learn the layout once and use it everywhere.',
      ],
    },
    {
      title: 'Error prevention',
      question: 'How is the system designed to avoid mistakes?',
      example: 'Similar features grouped together',
      findings: [
        'The app is mostly read-only, so **there’s little room for mistakes.**',
        'Tags like “stressed” or “travel” come with no guidance, so users may tag inconsistently.',
      ],
    },
    {
      title: 'Recognition rather than recall',
      question: 'Is there enough information on the surface to know where you’ll go next?',
      example: 'Breadcrumbs, onboarding, pagination',
      findings: [
        'There are no breadcrumbs or “you are here” cues, so users can lose their place.',
        '**There’s no way to jump between related views**, like Sleep to Readiness, without backing out.',
      ],
    },
    {
      title: 'Flexibility and ease of use',
      question: 'Does the experience differ between novice and expert users?',
      example: 'Keyboard shortcuts; shortcuts for efficiency',
      findings: [
        'Novices get lost in terms like HRV and latency, and don’t know which score matters.',
        'Experts move between days, weeks and months, and know how each metric applies to them.',
      ],
    },
    {
      title: 'Aesthetics',
      question: 'Can you strip the screen down to its main components?',
      example: 'White space, simplicity',
      findings: [
        'Simple type and clean card layouts keep each screen focused on its main data.',
        '**Navy on dark navy is too subtle**, so older users struggle to tell sections apart.',
      ],
    },
    {
      title: 'Help users find errors',
      question: 'Are mistakes easy to identify?',
      example: 'Toast notifications, red Xs vs. green checkmarks',
      findings: [
        'Green checkmarks and blue buttons confirm positive actions, like “Sync complete.”',
        'Red marks low scores, like poor sleep, rather than actual errors.',
      ],
    },
    {
      title: 'Help and documentation',
      question: 'Can users learn how to navigate the experience if needed?',
      example: 'FAQs, a help assistant, contact info',
      findings: [
        'Users can learn the app, but some features are tucked away and easy to miss.',
        'There’s **no FAQ or help assistant**, which is why an AI guide would help.',
      ],
    },
  ]}
