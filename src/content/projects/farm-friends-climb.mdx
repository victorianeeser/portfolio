<ConceptDemo id="concept" title="The Concept">

Farm Friends Climb is a tap-to-steer, auto-bounce climber styled after Jelly Jump. Players tap left or right to steer their character upward across cloud platforms, climbing as high as they can before missing a platform ends the run.

I chose this mechanic over a traditional platformer (too much scope risk for a three-week build) and a Crossy Road-style runner (too close to a game that already has its own farm-animal cast).

Tap controls, rather than tilt, meant the game also had to work reliably during laptop browser testing, not just on a phone. The result is a mechanic that's one-handed, learnable in seconds, and fast enough to replay in short bursts: exactly what a marketing game needs to keep players coming back.

</ConceptDemo>

<SectionTitle level={3}>System Map</SectionTitle>

Before designing screens, I mapped how the game moves between them: every screen and run state, and what sends the player from one to the next. Then I zoomed into the climb itself and listed the checks the game runs on every frame. The map became the plan for the build, so each state on it is a screen or a run state in the code.

<SectionTitle id="visual-design">Visual & Brand Design</SectionTitle>

The game uses detailed, soft-shaded pixel art rather than blocky 8-bit: 64×64px character sprites set against a sky that shifts through eight color stops, from a warm sunset gold to a deep night navy, as the player climbs higher. Bounce speed ramps up along the same arc, tying pacing directly to the visual progression.

<SkyClimb />

Each run starts on a static barn-and-grass scene before the climb begins. Cloud platforms come in four variants, and obstacles shift with the sky: a bee and a curling wind gust by day, birds as the sun sets, and an owl as night falls.

<Platforms />
